# Portfólio — Lívia Nunes

Site responsivo com HTML, CSS e JavaScript, servido com a biblioteca padrão do Python 3.12. Não requer instalação de dependências, banco de dados ou credenciais.

## Executar

```sh
cd /workspace/portf-lio
python app.py
```

A porta padrão é 8000. Para trocar: `PORT=8001 python app.py`.

## Conteúdo e recursos

- Navegação por seções, menu mobile, animações com respeito à preferência de movimento reduzido.
- Filtros de projetos, detalhes em modal, abas de formação e conquistas.
- Currículo para download em texto.
- Fundo futurista animado com halos em magenta e violeta sobre preto, feito em CSS.
- Tipografia pixelada local (Silkscreen e VT323), terminal digitado e glitch sutil.
- Paralaxe do fundo e brilho/inclinação suave dos cartões ao mover o mouse.
- Botão de pausa das animações, com preferência salva neste navegador. A configuração de movimento reduzido do dispositivo é respeitada automaticamente.
- Ilustrações feitas em CSS, sem dependências de imagens.
- Todas as fontes são locais; as licenças OFL ficam em `static/fonts/`.

O conteúdo foi baseado nas referências visuais fornecidas. Confirme os dados biográficos e profissionais antes da publicação. Os projetos de robótica e gestão são apresentações conceituais; seus links e detalhes reais ainda precisam ser incluídos. O currículo usa o conteúdo do site e pode ser substituído por um PDF definitivo.

PHP não é necessário para a versão atual. Um formulário com envio real pode ser integrado futuramente a um backend, com destino e serviço de envio definidos.
